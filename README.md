# بوصلة التمويل

موقع عربي لعروض شركات التداول الممول (Prop Firms)، وقواعد كل تحدي بالأرقام، وحاسبة قواعد.

## الصفحات

| الرابط | المحتوى |
| --- | --- |
| `/` | العروض: نسبة الخصم، الكود، وعدّاد الوقت المتبقي |
| `/firms/` | كل الشركات |
| `/firms/<شركة>/` | صفحة الشركة: عروضها وتحدياتها ومعلومات السحب |
| `/firms/<شركة>/<تحدي>/` | قواعد التحدي بالدولار + حاسبة القواعد |
| `/compare/` | مقارنة كل التحديات مع فلتر الدولة |
| `/calculator/` | الحاسبة لأي تحدي |

## تعديل البيانات

كل شي في ملف واحد: `lib/data.ts`

- **رابط الأفلييت**: غيّر `link` لكل شركة في `FIRMS`.
- **كودك الخاص**: `myCode`.
- **إضافة عرض**: أضف عنصر في `OFFERS`. حط `exclusive: true` للعروض الحصرية، و`endsAt` بصيغة `2026-11-30T23:59:00+02:00` عشان يشتغل العدّاد.
- **إضافة تحدي**: أضف عنصر في `CHALLENGES` بنفس شكل الموجود، وبتنعمل صفحته تلقائياً.

بعد أي تعديل ورفعه على `main`، الموقع بيتحدث لحاله خلال دقيقتين.

## حاسبة القواعد

المنطق في `lib/rules.ts`، والاختبارات في `tests/rules.test.ts`:

- **قبل الصفقة**: بتحسب المسافة عن حد التصفية (الثابت أو المتحرك)، والحد اليومي، وحد الخسارة المفتوحة، وبتطلع أقصى حجم صفقة والحجم المقترح مع هامش أمان.
- **جاهزية السحب**: بتفحص الهدف، قاعدة Consistency، الأيام الرابحة، أيام التداول، وقاعدة أكبر خسارة.
